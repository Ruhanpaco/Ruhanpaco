## About

I'm **Ruhan Pacolli**, a Software Engineer and the CEO & Founder of **EliteDev Agency**.

I started building websites at 9 and have been exploring technology ever since. My work now spans **web applications, mobile development, backend systems, cloud infrastructure, APIs, automation, IoT, and open source**.

I enjoy projects where software meets the physical world. Sometimes that means building a web application. Sometimes it means making an ESP32 talk to an NFC reader, a smart-home platform, and an access-control protocol.

I also contribute to the tech community through volunteer work, open-source projects, and technology events. Outside of software, I play **volleyball and paravolley**.

> Build something. Break something. Figure out why it broke.

## What I'm Building

### 🏠 Aliro HomeKey

An open-source access-control project built around **ESP32**, exploring how modern digital keys and smart-home ecosystems can work together.

**Exploring:**

`Aliro` `Matter` `ESP32` `NFC` `Apple Home Key` `Samsung Home Key` `Google Home` `Home Assistant` `MQTT`

The goal is to make modern access technology more approachable for developers and makers, while experimenting with interoperability between ecosystems.

**Project:** [github.com/Ruhanpaco/Aliro-homekey](https://github.com/Ruhanpaco/Aliro-homekey)

### 🏢 EliteDev Agency

**EliteDev Agency** is my software development company, focused on building digital products, custom software, automation, and modern web applications.

**Website:** [elitedev-agency.com](https://elitedev-agency.com)
